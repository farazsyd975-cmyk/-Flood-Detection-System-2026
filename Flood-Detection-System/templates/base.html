FLOOD DETECTION SYSTEM

A machine learning engineering platform for early flood hazard detection, environmental telemetry analysis, and spatial risk classification across Punjab, India.

MONITORED REGIONS

Jalandhar • Phagwara • Amritsar • Ludhiana • Kapurthala • Hoshiarpur • Nawanshahr

PROJECT METHODOLOGY

Built with Python Flask, Scikit-Learn Random Forest, and Leaflet.js OpenStreetMap. Risk indicators reflect localized machine learning classifications calibrated against hydrological parameters.

Department of Computer Science & Engineering • B.Tech AI/ML Engineering Project Local Database: SQLite 3 • Ingestion: Open-Meteo & Regional Hydrological Calibration
